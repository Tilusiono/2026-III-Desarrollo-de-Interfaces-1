## Caso complejo

Construya un gestor de estudiantes con funciones separadas para leer, normalizar, validar, mostrar errores, crear y renderizar. Añada `iniciar()` y `destruir()` para registrar y retirar listeners.

### Criterios de aceptación

- El programa debe ejecutarse sin errores no controlados.
- Los nombres deben seguir `camelCase`.
- Deben existir pruebas de valores límite.
- La salida debe ser clara y verificable.
- No se deben mezclar contenidos de otros temas salvo elementos básicos indispensables.

## Reto de depuración

Introduzca deliberadamente tres errores relacionados con este tema, registre los mensajes de consola y corrija cada causa. Explique por qué la corrección funciona.
