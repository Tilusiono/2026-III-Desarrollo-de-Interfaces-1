# Práctica: Variables, constantes y tipos

## Objetivo

Modelar información con declaraciones correctas, ámbitos claros y tipos coherentes.

## Preparación

Cree un archivo JavaScript con el nombre sugerido por el número del tema. Active la consola del navegador o ejecute el archivo con Node.js. Cada ejercicio debe incluir casos válidos, límites e inválidos.

## Caso complejo

Modele el estado de una sesión con identificador, usuario, fecha, autenticación, último error, intentos y configuración. Muestre `console.table`, valide tipos y explique cinco decisiones.

### Criterios de aceptación

- El programa debe ejecutarse sin errores no controlados.
- Los nombres deben seguir `camelCase`.
- Deben existir pruebas de valores límite.
- La salida debe ser clara y verificable.
- No se deben mezclar contenidos de otros temas salvo elementos básicos indispensables.

## Reto de depuración
