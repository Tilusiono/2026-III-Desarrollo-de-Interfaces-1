## Caso complejo

Implemente un tarifario escalonado y un motor de elegibilidad crediticia usando constantes intermedias con nombres claros. No use `if`, `switch` ni bucles.

### Criterios de aceptación

- El programa debe ejecutarse sin errores no controlados.
- Los nombres deben seguir `camelCase`.
- Deben existir pruebas de valores límite.
- La salida debe ser clara y verificable.
- No se deben mezclar contenidos de otros temas salvo elementos básicos indispensables.

## Reto de depuración
